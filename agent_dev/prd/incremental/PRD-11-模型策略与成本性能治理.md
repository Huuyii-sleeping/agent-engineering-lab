# PRD-11 模型策略与成本性能治理

## 目标

建立可配置的模型路由与成本控制机制，在保证效果的同时降低延迟与费用，适配更多业务场景。

## 范围（In Scope）

- Model Router（按任务类型/复杂度/风险分配模型）。
- Token Budget Manager（预算与硬阈值控制）。
- 退化策略（主模型不可用时降级）。
- 性能策略（并发、超时、重试、缓存）。

## 非目标（Out of Scope）

- 跨厂商复杂竞价调度。
- 多区域跨云容灾。

## 功能要求

- 路由维度：`planning/coding/review/ops`。
- 每会话与每日预算上限。
- 请求级 timeout/retry 策略可配置。
- 常见查询支持响应缓存（含失效策略）。
- 记录每次调用的成本估算与延迟。

## 验收标准（AC）

- AC-11-1：不同任务可命中不同模型策略。
- AC-11-2：预算超限时系统能降级或拒绝并给出理由。
- AC-11-3：主模型故障可自动切换备选模型。
- AC-11-4：在相同任务集下，总体成本与延迟显著下降。

## 实施顺序

1. 先做路由与预算基础设施。
2. 再做超时重试与降级切换。
3. 最后做缓存与成本统计面板。
