# PRD-19 MCP 与外部能力总线

## 目标

让外部能力系统与原生工具处在同一控制面，而不是作为孤立外挂存在。

## 范围（In Scope）

- MCP Client。
- 原生工具与 MCP 工具统一路由。
- 外部 server 生命周期管理（启动、请求、响应、失败）。
- 外部能力元信息暴露与权限边界。

## 非目标（Out of Scope）

- 完整插件市场与商业分发体系。
- 所有第三方协议的统一抽象。

## 功能要求

- 模型发起工具调用时，tool router 需先判断：
  - native tool
  - MCP tool
- MCP client 至少负责：
  - 启动外部进程或连接 server
  - 发送请求
  - 接收响应
- 外部工具结果必须与原生工具结果使用一致的回填契约。
- MCP 工具同样受安全、观测、重试和权限控制约束。
- 可向模型暴露外部能力说明，但不应破坏现有原生工具面。

## 验收标准（AC）

- AC-19-1：同一轮工具调度中可同时调用原生工具与 MCP 工具。
- AC-19-2：MCP 调用失败时，能返回结构化错误并可观测。
- AC-19-3：外部工具不会绕开权限边界和审计链路。
- AC-19-4：新增一个 MCP server 时，无需重写主循环。

## 实施顺序

1. 先实现最小 MCP client 和统一 tool router 分流。
2. 再补 server 生命周期与错误处理。
3. 最后接入权限、观测、提示词说明和验证用例。
