## Why

当前 Web Chat Console 左侧区域仍偏工程草稿：顶部品牌图标和名称不够精致，功能入口看起来像可用但实际尚未开发，会话列表缺少删除、重命名、置顶等基础管理能力，底部连接状态占用空间且视觉不协调，侧栏折叠也缺少过渡反馈。需要先把左侧作为高频导航面打磨到可继续承载后续功能的状态。

## What Changes

In Scope:
- 替换左上角品牌图标与名称，不再显示 `Agent`。
- 左侧功能入口展示为待开发状态，避免误导为已可用入口。
- 为历史对话增加本地 Web 侧删除、重命名、置顶操作。
- 删除左侧底部连接状态，将连接状态保留在顶部紧凑图标中。
- 在左侧底部增加仅图标展示的个人设置入口，用于承载自定义设置。
- 为左侧折叠/展开增加平滑过渡动效。
- 将消息身份与图标放在消息正文外部，并为用户与 AI 回复正文统一增加聊天气泡。
- 使用成熟 Markdown 渲染插件增强回复内容的标题、列表、表格、引用和代码高亮展示。
- 使用成熟图标库统一替换页面内手写图标。

Out of Scope:
- 不新增 agent service 或 BFF endpoint。
- 不修改 agent session 文件结构。
- 不实现功能入口对应页面。
- 不做多端同步的会话管理。
