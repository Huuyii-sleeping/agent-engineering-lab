# 设计

## 数据来源

全部复用现有 SkillHubPage props：

- `skills`：计算状态、来源、成熟度、安装和升级数量。
- `auditEvents`：展示全局近期操作流。
- `registrySettings`：继续支撑健康摘要。

## UI 结构

在现有页面中增加三块能力：

1. 筛选面板新增状态、来源、成熟度筛选按钮。
2. 健康摘要下方新增 overview strip，展示来源和状态分布。
3. 筛选面板底部新增 recent operations，全局展示最近 6 条审计事件。

## 筛选规则

筛选条件组合方式：

- 搜索关键词：匹配名称、摘要、来源、发布者、运行时、标签。
- 分类：现有分类筛选。
- 状态：新增 status 筛选。
- 来源：新增 registry source 筛选。
- 成熟度：新增 maturity 筛选。
- 已安装：现有开关。

## 风险

- 全局审计事件只展示当前 BFF 返回的本地近期事件，不代表远端全局事件。
- 筛选维度增加后移动端空间更紧，因此继续使用现有按钮列表布局并允许换行。
