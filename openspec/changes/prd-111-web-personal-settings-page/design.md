## Decisions

1. 使用应用内页面切换，不引入路由依赖。
   - 理由：当前 Web Console 是单页状态驱动应用，还没有路由层；新增路由会扩大改动范围。

2. 设置页复用现有 sidebar 和主题状态。
   - 理由：用户希望“新开一个页面”，但仍处于 Web Console 内部，保留左侧导航更方便返回会话。

3. 设置内容先以本地展示和已有状态为主。
   - 理由：当前没有账号、认证或设置后端接口，本轮先完成页面结构和交互入口。

4. 左下角三个设置 icon 分别打开同一个设置页的不同分区。
   - 理由：符合已有个人设置、偏好设置、系统设置三个入口，同时避免做多个空页面。
