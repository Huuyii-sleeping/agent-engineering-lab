# 设计

## 状态来源

在 Web App 内维护单个进行中的生命周期操作：

```ts
{
  skillId: string;
  kind: "primary" | "rollback";
}
```

`primary` 覆盖下载、安装、升级、卸载这些由主按钮触发的动作；`rollback` 覆盖回滚按钮。

## 交互规则

- 任意生命周期操作进行中时，禁用 Skill 卡片和详情面板中的生命周期按钮。
- 当前正在执行的 Skill 按钮显示 `处理中`。
- 详情确认弹窗仍然保留，用于提交操作前确认影响范围。
- 上传自定义 Skill 不纳入本阶段范围。

## 实现方式

- App 使用 state 传递进行中状态给 SkillHubPage。
- App 使用 ref 做同步守卫，避免同一渲染周期内重复触发。
- `finally` 中清空状态，保证失败路径也能恢复按钮。
- SkillHubPage 只负责展示和禁用，不直接管理异步生命周期。

## 风险

- 当前设计只允许一个生命周期操作同时进行，偏保守但更容易保证前端状态一致。
- 后端如果请求耗时较长，用户会看到全局生命周期按钮禁用，但不会影响筛选、查看详情等只读操作。
