# production-skillhub-operation-pending

## Why

SkillHub 的下载、安装、升级、卸载和回滚已经接入真实生命周期接口，但当前操作触发后按钮没有进行中状态。用户在请求未完成时可能重复点击，造成重复请求、状态竞争和误判。

本阶段增加生命周期操作忙碌态，让正在执行的 Skill 操作可见，并在请求完成前禁用其它生命周期按钮。

## What Changes

- App 记录当前进行中的 Skill 生命周期操作。
- SkillHubPage 接收操作状态，禁用生命周期按钮并显示处理中。
- 操作成功或失败后清空进行中状态。
- 测试覆盖进行中状态的渲染。

## Non-Goals

- 不新增 BFF API。
- 不改变后端生命周期状态机。
- 不引入队列或并发任务管理。

## Acceptance Criteria

- 触发 Skill 生命周期操作后，相关按钮显示处理中。
- 请求未结束前，页面生命周期按钮不可重复触发。
- 操作成功或失败后恢复按钮状态。
- 页面测试覆盖进行中状态。
