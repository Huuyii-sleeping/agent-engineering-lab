### 3. daemon 已经从占位符推进到真实长期服务入口

- `runDaemon()` 不再只是输出一行提示
- 现在会初始化共享 `AgentHost`
- 然后复用同一 host 启动长期 HTTP service

这意味着 `agent-cli daemon` 已经有真正的“宿主进程 + 服务面”语义，而不是空壳命令。

### 4. daemon 单实例锁已经补上

- 新增独占锁实现 [apps/agent-cli/src/entrypoints/daemon-lock.ts](/D:/项目/agent/apps/agent-cli/src/entrypoints/daemon-lock.ts)
- 锁文件位置：`.runtime/daemon.lock`
- 第二个 daemon 实例启动时，如果第一个实例还活着，会直接失败，错误码语义是 `AGENT_DAEMON_ALREADY_RUNNING`
- 如果锁文件存在但记录的进程已经不存在，会自动回收陈旧锁并继续启动

这是当前最重要的新增硬化点，因为它把 daemon 从“能跑”推进到“不会重复跑坏”。
