### CLI / TUI 当前已经落地的产品面

- 共享终端 renderer
- `/model`
- `/permissions`
- `/approvals`、`/approve`、`/reject`
- `/cost` / `/usage`
- `/compact`
- `/add-dir`
- `/redraw`
- `/clear` 新会话语义
- `!<cmd>` shell shortcut
- approval replay 基础闭环
- TUI 右侧 runtime / activity 面板
- workspace roots、approval queue、token / cost、theme 等状态展示
- 多行 composer 输入闭环：
  - `/compose`
  - `/preview`
  - `/pop [n]`
  - `/send`
  - `/cancel`
- composer 模式下普通文本追加到 draft，不直接请求模型
- composer 模式下空行会被保留进 draft
- composer 模式下 `approve` / `批准` / `yes` 这类文本不会误触本地审批动作
- `/preview` 以带行号的结构化方式展示草稿
- CLI prompt、TUI prompt / footer / runtime panel 已体现 draft 状态
- TUI 在 composer 模式下会显示独立 Draft panel
- `/use` 支持 index / unique prefix / `latest`
- `/next`、`/prev` 支持本地循环切换 session
- `/sessions` 与 TUI Sessions panel 会展示序号、active 状态和切换提示
- TUI 键盘快捷键：
  - `Ctrl+N` 下一会话
  - `Ctrl+P` 上一会话
  - `Ctrl+L` 重绘
  - `Esc` 取消草稿
- `/help` 支持 topic：
  - `/help draft`
  - `/help sessions`
  - `/help runtime`
  - `/help approvals`
  - `/help transcript`
  - `/help all`
- 交互 CLI / TUI 支持 `Tab` 补全：
  - slash command
  - help topic
  - session selector
  - theme / permissions / model 等高频本地参数
- transcript 本地浏览能力：
  - `/history`
  - `/history prev`
  - `/history next`
  - `/search <query>`
  - `/peek <index>`
  - `/tail`
- command palette / launcher：
  - `/palette`
  - `/palette <query>`
  - `/palette open <index>`
  - palette 结果按 session 缓存，支持直接按 index 执行
  - TUI 内独立 Palette panel
  - `Up` / `Down` / `Ctrl+N` / `Ctrl+P` 本地切换选中项
  - palette 打开时空行回车执行选中项
  - palette 打开时普通文本回车刷新本地 query，不进入模型链路
- TUI 左侧控制面已改成更紧凑的 `Guide` + `Shortcuts`
- TUI help 快捷入口：
  - `Ctrl+G`
- TUI palette 快捷入口：
  - `Ctrl+K`
- TUI Conversation panel 已支持 tail / history / search / peek 本地浏览状态
