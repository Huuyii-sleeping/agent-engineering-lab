## 下一步最自然的方向

如果继续往“更像 Claude Code，但更产品化”的方向推进，下一项优先级建议是：

1. palette overlay polish：继续把 command bar / results 浮层做得更像真正的 launcher，比如更轻的结果块、统一的结果密度和更克制的状态提示
2. transcript 深度浏览第二阶段：更细的滚动定位、长内容折叠和 search focus 的结果截断策略
3. draw workflow 第二阶段：把 draw surface 从本地 workflow 切换继续接到真实图像生成执行链路
