## 目录用途

`operations/` 里的每篇文档只回答一类长期可复用的操作问题：

- 为什么要这么分层
- 怎么做
- 适用场景
- 优点
- 代价和风险
- 如何用它讲清楚项目

## 后续原则

- 不再为每次小拆分单独写一篇流水账式学习文档
- 一篇文档对应一种长期可复用的操作类型
- PRD 和 OpenSpec 只记录变化范围与验收，不承担架构主文档职责
- 架构名词边界优先在术语表里统一
