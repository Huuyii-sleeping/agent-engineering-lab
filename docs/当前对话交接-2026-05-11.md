## 当前代码状态

本轮重构的核心目标，是让 CLI、HTTP service、未来 Web 接入不要再各走各的装配与执行路径，而是逐步收敛到同一条主线。

已经落地的代码边界：

- `apps/agent-cli/src/bootstrap/app-runtime.ts`
  - 抽出共享应用装配入口。
  - `cli.ts`、`server.ts`、`agent-service.ts` 都开始复用这套装配。
- `apps/agent-cli/src/runtime/query-runtime.ts`
  - 抽出统一 query 执行入口。
  - 用户消息注入、系统消息拼接、工具解析、循环执行、结果提取开始走共享路径。
- `apps/agent-cli/src/runtime/tool-runtime.ts`
  - 抽出统一 tool 执行边界。
  - 开始显式区分 `base / subagent / mcp` 执行目标，并收口保护执行逻辑。
- `apps/agent-cli/src/tools/registry.ts`
  - 新增 builtin tool registry 第一轮。
  - 开始把 `base + subagent` 的工具声明、preview、handler 解析集中到一个入口。
- `apps/agent-cli/src/tools/protocol.ts`
  - 新增统一 tool registration 协议层。
  - 开始把 builtin / MCP 都收口到同一份工具元数据视图。
- `apps/agent-cli/src/tools/service.ts`
  - 新增显式 `ToolService`。
  - 开始统一承载工具发现、metadata、preview 与执行，而不是继续暴露 resolver function。
- `apps/agent-cli/src/tools/index.ts`
  - 已退回到默认 `ToolService` 的薄包装。
  - 主路径开始面向 `ToolService`，而不是继续直接依赖若干工具函数。
- `apps/agent-cli/src/runtime/query-messages.ts`
  - 抽出 query 相关共享 message helper。
- `apps/agent-cli/src/runtime/query-notifications.ts`
  - 抽出 scheduled / subagent / background / team 通知收集与动态 system message 组装。
- `apps/agent-cli/src/runtime/query-tool-results.ts`
  - 抽出 tool output 分析、task id 解析、write side effect 跟踪、todo 完成判断。
- `apps/agent-cli/src/runtime/query-preparation.ts`
  - 抽出 query round 前置准备阶段。
  - 已收口 `SessionStart hook`、memory auto extract、autonomy tick、scheduler tick、dynamic system messages、memory injection。
- `apps/agent-cli/src/runtime/query-model.ts`
  - 抽出 query 的模型请求与恢复阶段。
  - 已收口 prompt envelope、preflight compact、budget policy、fallback、continue、backoff、失败收尾。
- `apps/agent-cli/src/runtime/query-tools.ts`
  - 抽出 query 的工具执行阶段。
  - 已收口 tool hook、tool observability、tool message 回写、write side effect、todo/task 状态联动。
- `apps/agent-cli/src/runtime/query-finalization.ts`
  - 抽出 query 的收尾阶段。
  - 已收口 assistant-only round 计数、auto delivery follow-up、Stop hook 收尾。
- `apps/agent-cli/src/runtime/query-engine.ts`
  - 新增显式 `QueryEngine`。
  - 开始统一承载 query round orchestration，而不是继续让调用方依赖 loop function。
- `apps/agent-cli/src/runtime/query-types.ts`
  - 抽出 query engine 与 runtime 共享类型。
- `apps/agent-cli/src/agent-loop.ts`
  - 已退到兼容 wrapper 角色。
  - 当前 query 主语义已经转到 `QueryEngine`。
