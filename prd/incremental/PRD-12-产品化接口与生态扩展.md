# PRD-12 产品化接口与生态扩展

## 目标

将当前 CLI Agent 升级为可嵌入、可集成、可运营的产品能力：提供服务接口、插件机制和标准化部署配置。

## 范围（In Scope）

- API 服务层（HTTP/WebSocket）。
- 插件生命周期管理（安装、启停、权限、版本）。
- 多会话与租户隔离基础能力。
- 部署配置模板与运维脚本。

## 非目标（Out of Scope）

- 商业计费系统。
- 完整 SaaS 控制台前端。

## 功能要求

- 提供 `/chat`, `/tools`, `/sessions`, `/health` 等基础接口。
- 会话隔离：每 session 独立状态与上下文。
- 插件元数据：`name/version/capabilities/permissions`。
- 支持插件签名校验与最小权限声明。
- 提供 Docker 化部署与环境配置示例。

## 验收标准（AC）

- AC-12-1：外部系统可通过 API 调用 Agent 完成端到端任务。
- AC-12-2：多会话并发不串状态。
- AC-12-3：插件可热装载并受权限约束。
- AC-12-4：标准化部署可在新环境一键起服务。

## 实施顺序

1. 先封装服务层与会话管理。
2. 再实现插件治理和权限边界。
3. 最后完善部署脚本与运维文档。
