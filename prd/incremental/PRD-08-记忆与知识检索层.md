# PRD-08 记忆与知识检索层

## 目标

让 Agent 具备长期记忆、项目知识检索与跨会话上下文恢复能力，减少重复说明与上下文丢失。

## 范围（In Scope）

- MemoryStore（短期/长期记忆分层）。
- 知识条目抽取与写入（会话摘要、决策、偏好、约束）。
- 检索接口（关键词 + 语义近似，先用轻量方案可替代向量库）。
- 记忆注入策略（按相关度和 token budget 注入）。

## 非目标（Out of Scope）

- 复杂知识图谱推理。
- 多租户云端记忆同步。

## 功能要求

- 短期记忆：最近会话关键事实（滚动窗口）。
- 长期记忆：项目级持久事实，写入 `.memory/*.jsonl`。
- 记忆条目结构：`id/source/type/tags/content/confidence/updatedAt`。
- 检索结果需返回 `score` 与来源。
- 注入上限可配置，防止记忆挤占主上下文。

## 验收标准（AC）

- AC-08-1：重启后可恢复之前记录的关键偏好与约束。
- AC-08-2：同类问题重复提问时，Agent 能基于历史回答保持一致性。
- AC-08-3：检索结果可解释（返回命中的条目和分数）。
- AC-08-4：记忆注入不导致主循环 token 明显失控。

## 实施顺序

1. 先做 MemoryStore 数据结构和持久化。
2. 再做检索与注入策略。
3. 最后做自动抽取与去重更新。
